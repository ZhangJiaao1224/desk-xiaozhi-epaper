用途：`config.h` 只从这张表取值，不许凭记忆写。表里没有的引脚，代码里就不许出现。
规则：**空着的格子不许猜**；凡是"设计选择"而不是"厂家定义"的格子，来源栏必须写明。

## 3. 墨水屏（4 线 SPI，SSD1683，400x300）

### 3.1 面板与驱动板接口（厂家定义，不要改）

驱动板上是 8 针排口（P1 / P2 两个同功能封装），线序即微雪标准：

| 驱动板针 | 信号 |
|---|---|
| 1 | `VCC_INT`（面板供电，驱动板自己出 3.3V） |
| 2 | `GND` |
| 3 | `DIN`（MOSI） |
| 4 | `CLK`（SCK） |
| 5 | `CS` |
| 6 | `D/C` |
| 7 | `RST` |
| 8 | `BUSY` |

驱动板自带 RT9193-33PB（3.3V LDO）与 TXB0108 电平转换，逻辑侧接 3.3V 即可。
**BS 必须接 GND**（`BS=L` 为 4 线 SPI），到货先看这块跳线。

### 3.2 本工程选定引脚（设计选择，到货按表接线）

| 信号 | GPIO | H1 针脚 | 可改？ | 备注 |
|---|---|---|---|---|
| SCK | GPIO12 | H1-18 | 可改 | |
| MOSI (DIN) | GPIO11 | H1-17 | 可改 | |
| CS | GPIO10 | H1-16 | 可改 | |
| DC | GPIO9 | H1-15 | 可改 | |
| RST | GPIO13 | H1-19 | 可改 | |
| BUSY | GPIO14 | H1-20 | 可改 | 输入；刷屏期间为忙，读它要带超时 |
| SPI 主机号 | 独立主机（计划 SPI2 / HSPI） | — | 可改 | 板载 OLED 走 I2C，本来也不抢 |
| 逻辑供电 | 3.3V，取自 H1-1 或 H1-2 | — | 否 | 与 ESP32 同电平 |
| 地 | GND，取自 H1-22 | — | 否 | 必须共地 |

选这六个脚的理由：它们正好是 H1 的第 15~20 针、连着 GPIO9~14，一条排线插完；
而且这批脚既不是 strapping，也没被音频、I2C、USB、UART、Flash、PSRAM 占用。

## 4. 按键与指示灯

| 信号 | GPIO | 可改？ | 备注 |
|---|---|---|---|
| BOOT 按键 | GPIO0 | 否 | 板载 S1；同时是 strapping，只能当输入 |
| 复位按键 | EN | 否 | 不是 GPIO |
| 板载 RGB 灯 | GPIO48 | 否 | WS2812 单颗，经 R3（0R） |
| 外接键 1「记一杯」 | GPIO4 | 可改 | 4 路独立轻触模块；按下拉低，内部上拉 |
| 外接键 2「报时」 | GPIO5 | 可改 | 同上 |
| 外接键 3（备用） | GPIO6 | 可改 | 同上；代码里先只打日志 |
| 外接键 4（备用） | GPIO21 | 可改 | 同上；H2-18 |
| 外接按键公共端 | GND | 否 | 接 H1-22，四键共地 |

按键模块是**设计选择**（2026-10-16 定），不是厂家定义；键 1~3 正好落在 H1-4/5/6 三根连着的针上，
键 4 走 H2-18。

## 5. 禁用引脚核对（ESP32-S3-WROOM-1-N16R8）

下列引脚任何情况下都不得分配给墨水屏或其它外设：

| 引脚 | 原因 |
|---|---|
| GPIO26 / 27 / 28 / 29 / 30 / 31 / 32 | 内部接 Octal Flash |
| GPIO33 / 34 / 35 / 36 / 37 | 内部接 Octal PSRAM（35/36/37 虽然引到 H2 上，仍然不能用） |
| GPIO19 / 20 | 原生 USB D- / D+ |
| GPIO43 / 44 | UART0 TXD0 / RXD0（烧录日志） |
| GPIO0 | BOOT strapping |
| GPIO45 / 46 | strapping；45 是 VDD_SPI 电压选择，上电必须为低 |
| GPIO3 | JTAG 选择 strapping |
| GPIO41 / 42 | I2C 总线（codec + OLED） |
| GPIO7 / 8 / 15 / 16 / 17 / 18 | 音频 I2S 与功放使能 |
| GPIO48 | 板载 WS2812 |
