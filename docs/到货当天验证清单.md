# 到货当天验证清单

原则：一次只验一件事，验不过就停下来查，不要连着往下做。
接线一律照 `hardware/引脚记录表.md`，不许凭记忆插线。

## 第 0 步：开箱记录（10 分钟）

- [ ] 拍开发板正反面，按 `hardware/引脚记录表.md` 第 7 节的清单逐条复核，结果写回该表第 8 节。
- [ ] 上电后用 I2C 扫描确认两个地址：ES8311 = `0x18`、SSD1306 OLED = `0x3C`（128x32）。
- [ ] 拍墨水屏面板背面丝印，确认驱动 IC 是 **SSD1683** 系（手册里 0x34 行引用的是 SSD1683）。
- [ ] 看驱动板 BS 跳线，确认接在 `L`（4 线 SPI）。
- [ ] 确认墨水屏驱动板 8 针口和杜邦线齐了；顺便看扬声器插头、USB-C 是不是数据线。
- [ ] 确认按键组是 4 路独立轻触（按下去会弹回来，不是自锁），四键各一个信号脚加一个公共端。

**卡住就停**：引脚表复核不过，后面一律不做。

## 第 1 步：点亮墨水屏（用极小工程，不碰小智）

目的：把屏幕和接线单独验掉，出问题时不用怀疑是小智的锅。

- [ ] 按引脚表接线：`SCK=GPIO12`、`MOSI=GPIO11`、`CS=GPIO10`、`DC=GPIO9`、`RST=GPIO13`、`BUSY=GPIO14`，
      3.3V 与 GND 从 H1 取。
- [ ] 烧点亮工程，先看全刷能不能正常出测试图。
- [ ] 三个耗时分三次测，各自打串口时间戳，和手册标称值对一下：
  - [ ] 全刷（标称 3s）
  - [ ] 快刷（标称 1.5s 或 1s）
  - [ ] 局刷（标称 0.42s）
- [ ] 验局刷差分：只改一小块，看是不是只变那一块、有没有残影。
      若局刷不生效或花屏，改试 `0x32` 自写局刷 LUT 的方案。
- [ ] 验 `0x21` 用不用、`0x22` 取哪个组合值：把候选值（`0xC7/0xCF/0xF7/0xFF` 等）都试一遍，
      记下哪个画面最干净。手册的标准流程里没有 `0x21`，GxEPD2 里有，两边对不上。
- [ ] 连续局刷 20 次，看残影到什么程度，据此定全刷间隔（初值：每小时一次）。

**验收**：能全刷、能局刷、无明显花屏。实测耗时写回设计文档第 6.3 节。
做不到就贴串口日志，先查 SPI 模式、BUSY 极性、BS 跳线这三处。

## 第 2 步：编自定义板型固件

- [ ] 填 `config.h`：I2S、I2C、PA、墨水屏 SPI、按键，全部来自引脚表。
- [ ] `config.json` 里板型标识必须唯一（例如 `desk-epaper-<你的名字>`），不许用官方标识。
- [ ] 编译，先不烧，确认能出 `build/merged-binary.bin`。
- [ ] 烧录，看串口日志有没有报错。

**验收**：串口无 ESP_ERROR，OLED 上出现小智的待机界面。

## 第 3 步：配网与对话

- [ ] 上电后手机连 `Xiaozhi-xxxx` 热点，浏览器进配网页，填 **2.4G** WiFi 密码
      （5G 和需要网页认证的网络连不上）。
- [ ] 设备显示 6 位验证码，去 xiaozhi.me 注册登录、添加设备、输验证码绑定。
- [ ] 控制台里选大模型，填 DeepSeek 或通义千问的 API Key。
- [ ] **关掉 OTA 自动升级**，防止自定义固件被官方固件覆盖。
- [ ] 喊"小智小智"对话，确认能听到回复。
- [ ] 看串口里有没有 `No server_time section found`；顺带确认墨水屏上的时间与手机一致
      （差整整 8 小时说明 `TZ` 被设了两次，见设计文档第 7.1 节）。

**验收**：能对话。到这一步语音链路就算通了。

## 第 4 步：验双屏分工

- [ ] 对话几轮，确认 OLED 上的状态和表情刷新及时、不发卡。
      OLED 只有 128x32，注意别让文字溢出或压到别的控件上。
- [ ] 确认墨水屏在对话期间不被高频刷新（它是日历看板，不该追动画）。
- [ ] 让日历跨过一分钟，确认墨水屏一分钟只刷一次。
- [ ] 连续跑到下次全刷（初值每小时一次），观察残影，再决定要不要调间隔。

**验收**：对话流畅；墨水屏每分钟稳定刷一次且无明显残影。

## 第 5 步：日历与联动

- [ ] 日历页按设计文档第 4.4 节的版式显示：日期星期 / 对时状态 / 大钟 / 喝水进度条 / footer 两行。
- [ ] 拔掉网线（或关掉热点）重启，确认屏幕显示「未对时」、大钟 `--:--`、footer 右侧是倒计时，且不崩。
- [ ] 上电后 45 分钟响起本地提醒，屏幕上「下次提醒」跟它对得上。
- [ ] 提醒后按一次键 1，杯数 +1；同一轮里再按一次，确认不加杯（只响一声提示音）。
- [ ] 说「刚才我喝水了」，杯数 +1 且刷屏；连着说两次，确认加两杯。
- [ ] 按一次键 2，听报时是否和屏幕上的时间一致。
- [ ] 断电再上电，确认杯数没丢；换个日期（或改系统时间）重启，确认杯数清零。
- [ ] 连续按 20 次键 1 和键 2，确认没有误触发、没有卡音频。

## 每次改动都要记

改完一个功能就写清楚：改了哪几个文件、怎么烧录、怎么验证、实测结果。
没中文注释的代码不许提交。
